# Led Map

Mapa de telas LED: **Rig** (montagem em metros), **Canvas** (pixels do processador) e **Dados** (cabeamento por portas). Exporta pixel map, layout (PNG/CSV) e projeto JSON.

App de arquivo único (`index.html`), sem build. Funciona offline e pode ser instalado no celular (PWA).

**Usar:** https://zuperney.github.io/ledmap/

**Instalar:** abra o link no Chrome (Android: menu ⋮ → *Instalar app*) ou no Safari (iPhone: Compartilhar → *Adicionar à Tela de Início*).

Os dados ficam só no navegador (localStorage). Use *⋮ Projeto → Exportar projeto (JSON)* para backup.
